## Before final Brightspace submission

1. Run the FCFF engine and workbench once in a fresh environment; complete the cold-run log.
2. Complete the course's locked changed-input record and frozen AI-use/validation record.
3. Push this folder and the original working model folder to GitHub.
4. Paste the required GitHub and recording links into Brightspace.

Copies in this folder do not automatically update when an original working file changes. If you revise a model or memo later, refresh the matching copy before submitting.
